Almost done

  1. Open your Live Set in Ableton Live.
  2. Create a MIDI track named GLOBAL CONTROL (no instrument needed).
  3. From the Browser, User Library › Presets › MIDI Effects › Max MIDI Effect, drop GLOBAL_CONTROL_BRIDGE on that track. One bridge per Live Set is enough.
  4. Open GLOBAL CONTROL from /Applications: it connects automatically (start order does not matter), scans the project and shows every plug-in instance. The SETUP panel checks Max for Live, the bridge installation and the connection, and can install or update the bridge for you.

If the bridge was not copied (no User Library found, or a different file already there), use SETUP › Install bridge in User Library in the app.
