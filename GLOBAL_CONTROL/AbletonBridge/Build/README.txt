GLOBAL CONTROL bridge - copy BOTH files into the same folder of the Ableton User Library
(default: ~/Music/Ableton/User Library/Presets/MIDI Effects/Max MIDI Effect/).
GLOBAL CONTROL.app can do it for you: SETUP > Install bridge in User Library.
Then create a MIDI track named GLOBAL CONTROL and drop GLOBAL_CONTROL_BRIDGE on it (one per Live Set).
